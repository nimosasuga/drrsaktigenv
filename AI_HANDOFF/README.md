# AI Handoff - DRR SAKTI GEN V

Folder ini berisi instruksi untuk melanjutkan pengembangan project DRR SAKTI GEN V dengan AI lain.

Gunakan urutan baca berikut:

1. `01_PROJECT_CONTEXT.md`
2. `02_GLOBAL_GOLDEN_RULES.md`
3. `03_CURRENT_WORKING_NOTES.md`
4. `04_CPANEL_DEPLOYMENT.md`
5. `05_PROMPT_FOR_NEXT_AI.md`

Catatan utama:

- Local `C:\laragon\www\drrsakti` adalah versi stabil dan sumber kebenaran utama.
- Project berjalan di Laravel 13.
- cPanel wajib memakai PHP 8.3.
- Jangan jalankan `npm run build` kecuali ada perubahan di `resources/js`, `resources/css`, atau konfigurasi Vite.
- Jangan upload `.env`, folder `storage`, `vendor`, `node_modules`, atau file cache lokal.
